# Cricket Match Scraper 🏏

A simple Python web scraper that collects cricket match information from Cricbuzz using Requests and BeautifulSoup.

## Features
- Extracts match names and series details.
- Collects team names and scores.
- Identifies live, completed, and upcoming matches.
- Exports match information to CSV.
- Includes basic error handling.

## Technologies
- Python
- Requests
- BeautifulSoup

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python scrapper.py
```

The extracted match information is displayed in the terminal and saved to `cricket_matches.csv`.
